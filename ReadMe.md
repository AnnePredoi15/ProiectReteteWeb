# Căutător de Rețete Culinare

Proiect realizat pentru laboratorul de Proiectarea Aplicatiilor Web.

## Cerințe îndeplinite:
- Structură HTML5 validă.
- Design CSS Responsive (adaptabil pe telefon, tabletă și desktop).
- Formular interactiv de căutare.
- Integrare asincronă cu un API extern (TheMealDB API).

## Tehnologii folosite:
- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript (ES6+, Fetch API)
- TheMealDB API
